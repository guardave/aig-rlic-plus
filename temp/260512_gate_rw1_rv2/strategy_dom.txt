Final Exam Result: Did Not Pass

This strategy was subjected to a rigorous final holdout test after the winning rule was selected. The test did not pass all required conditions. This does not necessarily mean the strategy is worthless — some failures reflect structural constraints (short holdout window, multiple-testing penalty, unusual market conditions) rather than model failure. The full findings are documented below so you can judge them in context.

Conditions that did not pass:

Return quality in the holdout period was insufficient: the strategy's risk-adjusted return (Sharpe ratio 0.31) fell well below the minimum required for a credit spread strategy (0.50). The holdout covered 2020-2026, a period dominated by the COVID recovery and a sharp rate-hiking cycle — conditions that compressed the strategy's historical edge.
The strategy lost money in the holdout on a net basis: annualised excess return was -13%, meaning it underperformed a passive position over the 2020-2026 test window.
Statistical confidence is insufficient: a bootstrap simulation shows the holdout return could plausibly be zero or negative by chance, so we cannot rule out that the result reflects luck rather than a genuine edge.
Multiple-testing check did not pass: after adjusting for the 381 independent combinations tested in the search phase, the winning strategy's result is not statistically distinguishable from chance at the required confidence level. This is the same correction used to prevent cherry-picking — the more combinations you test, the higher the bar the winner must clear.
How the Signal is Generated

Each month, the HY-IG spread (difference between ICE BofA HY OAS and IG OAS) is computed from FRED series BAMLH0A0HYM2 and BAMLC0A0CM. The 36-month rolling z-score is computed as: (current spread − 36-month mean) / 36-month standard deviation. When this z-score is negative, the spread is below its recent average — a benign credit environment. When it is positive, the spread is elevated relative to recent history — a warning signal. The strategy holds SPY when z-score < 0 and moves to cash when z-score ≥ 0. Monthly positions are rebalanced at each month-end based on the prior month's z-score value (1-month lead to avoid look-ahead bias).

How to Use This Indicator Manually

To monitor this signal as a research indicator:

Pull HY and IG OAS from FRED (BAMLH0A0HYM2 and BAMLC0A0CM) at month-end.
Compute the spread: HY OAS minus IG OAS in basis points.
Compute the 36-month rolling z-score: (current spread − 36-month mean) / 36-month standard deviation.
Read the z-score: negative means below average (hold SPY); zero or above means elevated (move to cash).
Apply the rule with 1-month lead: if this month's z-score < 0, hold SPY next month; if ≥ 0, move to cash next month.
Monthly rebalancing — z-score is updated each month as new spread data arrives. No model refitting required.
